# Better Tracking — нативная версия (Kotlin + Jetpack Compose)

Это переписанная на Kotlin версия приложения из `../better-tracking` (Capacitor + WebView).
Логика перенесена из `www/app.js` функция в функцию: модель данных, расчёт тоннажа,
калории (Keytel 2005 по пульсу или MET × базовый обмен по Mifflin-St Jeor), сценарии
тренировки, сплиты, библиотека из 204 упражнений, профиль, ИМТ, график веса и BLE-пульс.

## Структура

```
app/src/main/
  assets/exercise-catalog.json        каталог упражнений (сгенерирован из www/exercise-catalog.js)
  java/com/example/pulseworkout/
    MainActivity.kt
    data/      Model.kt (JSON-модель как в app.js), Catalog.kt (категории, кардио, цвета), Repository.kt (хранение)
    logic/     Calc.kt — тоннаж, калории, тренды, даты, форматирование
    ble/       HeartRateManager.kt — поиск и подключение пульсометра (Heart Rate Service 0x180D)
    ui/        AppViewModel.kt (сценарии), App.kt (навигация), Feedback.kt (вибро и звук)
    ui/screens Журнал, тренировка, библиотека, сплиты, профиль, браслет
```

## Сборка

Нужны JDK 17+ (установлен JDK 21 в `D:\Java`) и Android SDK (`D:\Android\Sdk`).

```bash
gradlew assembleRelease
```

Подписанный APK: `app/build/outputs/apk/release/app-release.apk`.

## Тест интерфейса

`gradlew testDebugUnitTest` прогоняет сквозной сценарий на JVM (Robolectric): онбординг → сплит →
тренировка → подход → статистика → журнал → профиль. Снимки экранов сохраняются в `app/screenshots/`.

`ScreenAtlasTest` снимает все экраны и состояния на демо-данных в `app/screenshots/atlas/` (A1…I4 — ветки user flow).
Они выложены в Figma BETR на странице «10 Screenshots»: рядом с каждым снимком пустой фрейм Draft для доработки.

## Отличия от WebView-версии

- `applicationId` — `com.example.pulseworkout.compose`, поэтому версия ставится **рядом** со старой и не удаляет её данные.
  Данные старой версии (localStorage WebView) автоматически не переносятся.
- Незавершённая тренировка сохраняется и переживает перезапуск приложения.
- Исправлено: удалённые упражнения из встроенного каталога больше не возвращаются после перезапуска,
  а упражнения, добавленные в «Прочее», не теряют эту отметку.
- Дата «сегодня» берётся по местному времени (в app.js — по UTC, из-за чего ночью дата могла сдвигаться).
- Экран «Статистика» в оригинале был недоступен из интерфейса; его сводка теперь показана вверху журнала.

## Суперсеты

В шапке активного упражнения — «Суперсет»: выбирается второе упражнение, и они объединяются в группу A/B/C
(`ExerciseInstance.supersetId`, у подходов — `Entry.supersetId`). После подхода в A сразу открывается подход для B,
отдых стартует после последнего упражнения круга. В карточке суперсета: «Подход» у каждого упражнения, крестик убирает
упражнение из группы, «В суперсет» добавляет ещё одно, «Завершить» завершает всю группу. В статистике тренировки суперсет
показан одной группой с меткой и буквами. Макеты — Figma BETR, страница 03 Workout, ряд «Суперсеты».

## Обновления через GitHub

При запуске приложение в фоне запрашивает `https://api.github.com/repos/<updateRepo>/releases/latest`.
Если номер в теге релиза (`v2.2.0` → `2.2.0`) больше `versionName`, показывается попап «Доступна версия…»
с текстом релиза; «Скачать» загружает первый `.apk` из файлов релиза и открывает системный установщик.

- Репозиторий и версия задаются в `gradle.properties`: `updateRepo=owner/repo`, `appVersion=2.1.0`. Пустой `updateRepo` отключает проверку.
- Как выпустить обновление: поднять `appVersion`, собрать `gradlew assembleRelease`, создать на GitHub релиз
  с тегом `v<appVersion>`, приложить APK и описание (оно попадёт в попап). Черновики и pre-release игнорируются.
- APK должен быть подписан тем же ключом, иначе Android откажется ставить его поверх. Репозиторий должен быть публичным
  (для приватного нужен токен, который нельзя безопасно хранить в APK).
- При первой установке Android попросит разрешить «Установку неизвестных приложений» для Better Tracking.

### Исправления логики (2.0)
- Удалённые упражнения и сплиты архивируются: история тренировок сохраняет их названия и цвета.
- Рекорд считается по эффективной нагрузке (учитывает гравитрон и вес тела), а не по весу на снаряде.
- Тренды и рекорды сравниваются только с более ранними тренировками (в том числе в тот же день).
- Журнал всегда считает «сегодня» заново: тренировки после полуночи не пропадают.
- FAB тренировки (`WorkoutFab`): без тренировки — запускает её; во время тренировки на других экранах — гантель
  с расходящимися кругами, возвращает к тренировке; на экране тренировки — красная «Стоп», завершает её. Таймера на FAB нет.
- Кардио в редактируемой (прошлой) тренировке вводится вручную, без живого таймера.
- Ошибочный подход можно удалить; номера подходов пересчитываются.
- После подхода автоматически стартует секундомер отдыха.
- Рост длительности тренировки не подсвечивается как «улучшение».
- Сохранение на диск вынесено из UI-потока; поиск не различает «е» и «ё».
